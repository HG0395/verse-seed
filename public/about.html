N행시 만들기가이드

사이트 소개·문의

작은 단어가 이야기가 되는 곳

한 줄 씨앗(VerseSeed)은 한국어 N행시의 초안을 만들고 다듬는 작은 작업실입니다. 별도 계정이나 API 키 없이 바로 시작할 수 있도록 만들었습니다. ‘씨앗 심기 → 피어난 문장들’이라는 흐름으로 단어를 입력하고 표현을 고치는 데 집중합니다.

무엇을 할 수 있나요?

2~12글자의 한글로 N행시를 만들고, 세 가지 분위기와 길이, 최대 10개의 후보를 선택할 수 있습니다. 각 행 편집, 후보별·전체 복사, 텍스트 다운로드를 지원합니다. 이름을 넣을 수 있지만 이름의 뜻이나 특정 인물을 이해해 생성하지는 않습니다.

어떻게 만들나요?

브라우저에 포함된 첫 글자 사전과 직접 작성한 문장 재료를 무작위로 조합합니다. 외부 AI 모델을 호출하지 않으며, 검색해서 기존 작품을 가져오지도 않습니다. 조합형 생성의 장점은 빠르게 초안을 보는 것이고, 한계는 표현이 반복되거나 문맥이 어색할 수 있다는 점입니다. 그런 부분을 직접 고칠 수 있도록 편집 기능을 제공합니다.

문의·오류 제보

GitHub에서 문의 또는 오류 제보하기 ↗

GitHub 계정이 필요하며 문의 내용은 공개됩니다. 사용한 브라우저, 문제가 발생한 동작, 기대한 결과를 적어 주세요. 비밀번호·토큰·전화번호 등 개인정보는 적지 마세요. 별도의 비공개 이메일 문의 창구는 운영하지 않습니다. 응답 시간을 보장하지 않습니다.

소스와 운영

공개 GitHub 저장소에서 코드와 변경 내역을 확인할 수 있습니다. 정적 파일은 Cloudflare Pages로 제공하며, 입력과 결과의 계정 동기화나 서버 저장 기능은 없습니다.
