자주 묻는 질문

정말 API 키가 필요 없나요?

네. N행시 생성은 브라우저 안의 사전과 문장 조합으로 처리합니다. 외부 AI 호출이나 로그인, API 키 등록이 없습니다. 생성 기능 자체에 API 사용료가 발생하지 않습니다.

어떤 단어를 입력할 수 있나요?

완성된 한글 음절 2~12개를 지원합니다. 공백은 자동으로 제외하며, 숫자·영어·이모지·단독 자모는 지원하지 않습니다. 단어의 글자 수가 행 수가 됩니다. 사전에 없는 글자는 해당 글자 뒤에 쉼표를 붙여 시작합니다.

같은 단어로 다시 만들면 달라지나요?

문장 조합을 무작위로 선택해 후보를 만듭니다. 한 번에 보이는 결과는 중복을 피하지만, 이전 생성과 같은 표현이 다시 나올 수 있습니다. 사전 기반이므로 단어의 의미를 깊게 이해하거나 이름에 맞춰 이야기를 만들지는 못합니다.

결과는 어떻게 보관하나요?

각 행을 수정하고 카드별 복사, 전체 복사, 텍스트 저장을 사용할 수 있습니다. 결과는 현재 탭의 메모리에만 있으며 새로고침하면 지워집니다. 입력이나 결과를 주소에 넣어 공유하지 않습니다.

광고와 개인정보는 어떻게 처리하나요?

생성 단어와 결과를 사이트 서버에 보내지 않습니다. 다만 Google 광고 스크립트와 호스팅 제공자는 접속 정보를 처리할 수 있습니다. 자세한 내용과 광고 설정 링크는 데이터 사용 안내에 있습니다. 광고 표시와 AdSense 승인은 Google의 심사·설정에 따릅니다.
